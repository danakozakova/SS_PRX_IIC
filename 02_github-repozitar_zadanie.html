Hodina 02 — GitHub repozitár

Zopakovanie tagov, nové tagy z bonusu H01, a vytvorenie vlastného GitHub repozitára.

📄 Pre rozcvičku si vytvor nový prázdny súbor vo VS Code — napr. rozcvicka.html

⭐ Bonus tagy z H01

Toto sú tagy z minulej hodiny, ktoré sme nestihli. Pridaj ich do svojho súboru 02_github-repozitar_kostra.html a vyskúšaj, čo robia.

Úloha 1 — Indexy: dolný a horný

Pridaj do súboru tieto riadky a pozoruj výsledok:

<p>Chemický vzorec vody: H<sub>2</sub>O</p>
<p>Pythagorova veta: a<sup>2</sup> + b<sup>2</sup> = c<sup>2</sup></p>

Otázky: Čo presne urobil <sub>? Čím sa líši od <sup>? Kde ešte v matematike by si použil tieto tagy?

Úloha 2 — Zvýraznenie a prečiarknutie

<p>Dnes som sa naučil(a): <mark>HTML je jednoduchý!</mark></p>
<p><del>HTML je ťažké</del> — HTML je zábavné!</p>

Otázky: Kde by si v reálnej stránke použil <mark>? A <del>?

Úloha 3 — Pohyblivý text

Toto je starý tag — moderné stránky ho nepoužívajú. Ale je zábavný:

<marquee>Pohyblivý text!</marquee>

Otázka: Prečo podľa teba vývojári prestali tento tag používať?

Úloha 4 — Vnorené tagy

Tagy môžeš kombinovať. Vyskúšaj:

<b><i>Tučná kurzíva</i></b>
<h2><u>Podčiarknutý nadpis</u></h2>
<b>Tučný text s <i>kurzívou</i> uprostred</b>

Otázka: Čo sa stane, keď zatváracie tagy nie sú v správnom poradí? Skús <b><i>text</b></i> — čo spraví prehliadač?

🔁 Rozcvička — Napíš to podľa screenshotu

Pozri si screenshot stránky. Tvojou úlohou je napísať HTML, ktoré vytvorí presne taký výsledok.

  1. Vytvor nový prázdny súbor vo VS Code (Ctrl+N) a ulož ho ako rozcvicka.html
  2. Pozri sa na screenshot a píš HTML zhora nadol
  3. Niektoré efekty nepoznáš — to je v poriadku. Hádaj a experimentuj
  4. Ulož a pozri výsledok v prehliadači (Live Preview)
💡 Tip: Vidíš text, ktorý je malý a nižšie? Alebo malý a vyššie? Zamysli sa, ako by sa mohol volať HTML tag, ktorý to robí — skús <sub> alebo <sup>.

🐙 GitHub — vytvor si vlastný repozitár

Repozitár = priečinok s projektom na GitHube. Každý bude mať vlastný.

Budete potrebovať emailovú adresu, ku ktorej máte prístup (školský alebo osobný). Ak nemáš, povedz učiteľke.

Postup

  1. 1

    Choď na github.com v prehliadači

    Klikni Sign up (vpravo hore)

  2. 2

    Zadaj svoju emailovú adresu

    Vytvor heslo — zapíš si ho!

    Vyber si username (meno profilu) — bude v tvojom linku, napr. jan-novak

  3. 3

    Prejdi cez overenie (puzzle / captcha)

    Klikni Create account

  4. 4

    Over email — GitHub ti pošle 6-ciferný kód

    Otvor email, skopíruj kód a vlož ho na GitHube

  5. 5

    Preskočte nastavenia (klikaj Skip / Continue) — nič neplať

  6. 6

    Klikni + (vpravo hore) → New repository

    Názov: SS_PRX_IIC

    Nastav: Public (nie Private!)

    Klikni Create repository

  7. 7

    Na stránke repozitára klikni uploading an existing file

    (alebo: Add file → Upload files)

  8. 8

    Presuň (drag & drop) svoj súbor moja-stranka.html do okna

    Alebo klikni choose your files a vyber súbor

  9. 9

    Dolu klikni Commit changes

    Súbor je teraz na GitHube! 🎉

  10. 10

    Skopíruj adresu svojho repozitára z prehliadača
    (bude vyzerať ako: github.com/jan-novak/SS_PRX_IIC)

    Pošli link

⚠️ Ak ti nepríde overovací email: skontroluj Spam / Nevyžiadaná pošta. Ak nie je ani tam, povedz učiteľke.

⭐ Bonus — GitHub Pages (živá webová stránka!)

Keď nahráš súbor, GitHub ti umožní zobraziť ho ako skutočnú webovú stránku na internete:

  1. V repozitári klikni Settings (vpravo hore)
  2. V ľavom menu klikni Pages
  3. V časti Branch vyber main → klikni Save
  4. Počkaj 1–2 minúty a obnov stránku
  5. GitHub ti ukáže link — napríklad:
    jan-novak.github.io/SS_PRX_IIC

Toto je tvoja prvá skutočná webová stránka prístupná z celého sveta! 🌍
